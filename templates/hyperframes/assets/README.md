# Job media

Place these local assets before preview or render when available:

- `input-video.mp4` — trimmed A-roll.
- `gsap.min.js` — generated with `npm run prepare:assets`.
- `fonts/smiley-sans-oblique.woff2` — the preferred licensed display font. If it is missing, composition text uses the CSS sans-serif fallback.

Do not use remote CDN assets in a reproducible render.
