# Assets

The source modules refer to the original job's local media under these paths:

- `assets/supporting/` for screenshots and product evidence;
- `assets/b-axis/` for the staged demonstration media;
- `assets/fonts/` for the display font;
- `assets/gsap.min.js` for the pinned GSAP runtime.

Those files are intentionally not copied here. Supply approved or synthetic replacements in the target job and keep private source media out of Git.
