# Required local assets

- `input-video.mp4` — provide your own 33.9-second test clip or adapt all timings.
- `gsap.min.js` — run `npm install && npm run prepare:assets`.
- `fonts/smiley-sans-oblique.woff2` — supply a properly licensed 得意黑 font file.

The original creator footage, audio, font binary, and rendered MP4 are intentionally excluded.
